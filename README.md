# Down 8 After a Late Touchdown — Go for 2 or Kick?

**DTSC 2301 — Portfolio Project 2**

Author: Micah Shelley

## Research Question

From 2016–2025, for NFL teams trailing by 8 points at the time of a try with under
10 minutes left in the 4th quarter, does attempting a 2-point conversion produce a
higher expected win probability than kicking the PAT, and do observed win rates
support the model's prediction?

## Files

- `notebooks/nfl_two_point_decision.ipynb` — full analysis: data loading, cleaning, EDA,
  baseline, logistic regression vs. gradient boosting, evaluation, interpretation, decision analysis
- `data/nfl_down8_tries_2016_2025.csv` — the 108 decision situations with model predictions
- `docs/nfl-two-point.html` — the published write-up
- `docs/project2/` — charts generated by the notebook

## Data Source

nflverse play-by-play data: https://github.com/nflverse/nflverse-data/releases/tag/pbp
The notebook downloads it automatically (about 180 MB) into `data/nfl_raw/`, which is git-ignored.

## How to Run

1. `pip install -r requirements.txt`
2. Open `notebooks/nfl_two_point_decision.ipynb` and run all cells (about 10 minutes, mostly model fitting)
